# נכסי המיתוג

## קובצי המקור

הקבצים הבאים הם קובצי המקור המקוריים ואין לערוך, להמיר, לדחוס או להחליף אותם במקום:

- `source/company-logo.pdf` - מקור וקטורי ראשי שממנו מופקים כל הנכסים.
- `source/company-logo.jpg` - צילום המקור שנשמר להשוואה חזותית ולשימוש כגיבוי בלבד.

## נכסים מופקים

| קובץ                           | שימוש                                                                 |
| ------------------------------ | --------------------------------------------------------------------- |
| `logo.svg`                     | הלוגו המלא במסכי הכניסה ובכותרת הצ'אט.                                |
| `logo.png`                     | גרסת רסטר איכותית של הלוגו המלא לשימושים שאינם תומכים ב־SVG.          |
| `favicon-16x16.png`            | favicon קטן לדפדפן.                                                   |
| `favicon-32x32.png`            | favicon רגיל לדפדפן ול־PWA.                                           |
| `apple-touch-icon-180x180.png` | אייקון למסך הבית במכשירי Apple.                                       |
| `icon-192x192.png`             | אייקון PWA בגודל 192x192.                                             |
| `maskable-icon.png`            | אייקון PWA בגודל 512x512 עם שוליים בטוחים של 20% מכל צד עבור Android. |

הלוגו המלא מופק עם רקע לבן צמוד לגבולות הגרפיקה כדי לשמור על קריאות הכיתוב השחור בערכת נושא כהה. אייקוני הסמל האדום מופקים עם רקע שקוף.

## צבעי המותג

- אדום ראשי: `#FF321A` - הצבע הווקטורי המדויק שחולץ מקובץ ה־PDF.
- שחור: `#0C0D0C` ו־`#0D0D0D` - שני ערכי השחור הקיימים בנתיבי המקור.
- לבן: `#FFFFFF` - רקע הלוגו המלא.

## החלפת הלוגו בעתיד

1. יש להחליף את שני קובצי המקור תחת `source/` תוך שמירה על שמות הקבצים. אין לערוך אותם במקום; יש לשמור תחילה עותק חדש של קובץ המקור שהתקבל.
2. יש לוודא שקובץ ה־PDF כולל נתיבים וקטוריים ושצבע הסמל מוגדר ב־`client/scripts/generate-branding-assets.mjs`.
3. משורש המאגר יש להריץ:

   ```shell
   node client/scripts/generate-branding-assets.mjs
   ```

4. יש לבדוק חזותית את `logo.png` ואת `maskable-icon.png`, ולאחר מכן להריץ את build ואת ה־typecheck של צד הלקוח.

המחולל קורא בלבד את `source/company-logo.pdf` וכותב מחדש רק את הנכסים המופקים שבתיקייה זו. קובצי המקור אינם משתנים.
